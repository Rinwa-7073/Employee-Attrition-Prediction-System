Employee Attrition Prediction System

About the Project

The Employee Attrition Prediction System is a Machine Learning project that predicts whether an employee is likely to leave an organization. It helps HR teams understand employee attrition patterns and make better decisions to improve employee retention.

Objectives

- Predict the likelihood of employee attrition.
- Analyze employee data using Machine Learning.
- Help organizations identify employee retention patterns.
- Display prediction results through a simple web application.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

Project Files

- "app (4).py" – Web application for making predictions.
- "Employee_Attrition_Prediction.ipynb" – Jupyter Notebook containing the analysis and model development.
- "employee_attrition_dataset.csv" – Dataset used for the project.
- "employee_attrition_model.pkl" – Saved Machine Learning model.
- "README.md" – Project documentation.

How to Run the Project

1. Download or clone this repository.
2. Install the required Python libraries:
   pip install pandas numpy scikit-learn streamlit
3. Open the project folder in your terminal.
4. Run the application:
   streamlit run "app (4).py"

Applications

- Employee attrition analysis
- HR decision support
- Employee retention planning
- Workforce management
